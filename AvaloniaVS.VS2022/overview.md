# AxamlCraft for Visual Studio

AxamlCraft is an **AXAML preview extension** for Visual Studio, forked from the original AvaloniaVS plugin.

## Features

- AXAML live preview (Previewer)
- AXAML code completion (IntelliSense)
- AXAML file icons
- Code snippets

## Note

This extension no longer bundles project templates. To create an Avalonia project, use the CLI templates:

```
dotnet new install Avalonia.Templates
dotnet new avalonia.app -o MyApp
```
